01 · 刘岱良

项目面诊：把「过程」改成「判断过程」

原片依据与内容拆解

已核实：已看到顾客描述年龄与困扰、医生在面部标记解释。原片约2分10秒；页面约1.4万赞。尚未完整核对开头与结尾的镜头顺序。

钩子：标题把年龄与具体困扰放在一起，便于同类人群识别。实际首2秒是否兑现这一承诺，仍待逐秒核实。

看点：值得研究的是：顾客怎么说、医生看什么、为什么这样判断。面部标记使口头解释有可指认的位置。

珊珊对应问题 → 优化方案

对应问题：珊珊的项目作品，标题讲双眼变化、封面强调全流程，抽查开场字幕为「塑形中」。用户进入后需要重新判断这条到底解决什么问题。

怎么改：封面、首句和正文统一为一个诉求；先保留顾客的一句原话，再给医生对应部位的判断镜头。避免用泛泛的「全脸年轻化」包住所有变化。

可执行示例：封面示例：眼周显疲惫，面诊先看什么？开头示例：她最在意的是眼周看起来疲惫，面诊时我先确认这两个信息。具体信息由医生按真实病例填写。

为什么：先让观众知道自己在看什么，再用可见证据解释方案；能减少内容范围不明带来的理解成本。

意义与复盘：从展示做了什么，转向展示医生如何思考。复盘前5秒留存及评论里是否出现与该诉求相关的具体提问，不能仅看总赞。

原片依据与内容拆解

已核实：原片约6分13秒。抽查开头讨论案例P图质疑；约2分07秒画面出现面部标记、镜前交流与消毒。仅确认这些观察点，不声称整条一镜到底或无处理。

珊珊对应问题 → 优化方案

对应问题：珊珊封面用「全流程」作承诺，但标题更突出眼周变化。流程与观看目标需要明确连接。

怎么改：同一案例做两个版本：45–75秒讲清关键判断；3–6分钟记录详细流程。短版每一步配一句「为什么保留这一步」，长版加清晰章节；不要靠加速堆满所有素材。

04 · 王恒

面诊Q&A：让问题推动回答

原片依据与内容拆解

已核实：约55秒；抽查开头可见就诊者在诊室提出注射相关诉求。页面约3万赞、3.9万收藏、1.6万分享。未验证对话是否自然发生、是否经过编排。

看点：问答双方、诊室场景和即时表达使内容有交流感。收藏和分享较高是公开互动信号，不能推断转化原因。

珊珊对应问题 → 优化方案

06 · 陈陈

恢复回访：时间本身就是栏目线索

原片依据与内容拆解

已核实：约54秒，2401赞、1086评论。开头画面与字幕明确「眼周提升第五天」，可见恢复状态。未核实后续恢复结局。

钩子：第5天是明确的时间坐标，让正在关注恢复过程的人迅速知道这一条的价值。

看点：真实状态比笼统的「恢复得很好」更具体。不能根据这一个人的画面，推导其他人的恢复时长。

珊珊对应问题 → 优化方案

对应问题：项目案例如果只拍当天前后，难以回答观众对后续变化的疑问。这是珊珊可补充的栏目机会，不是声称已审完全部作品后的缺失结论。

怎么改：为同一案例建立按实际复诊安排更新的回访系列。每条固定写清距项目多久、顾客自述、可见状态与医生解释；尽量保持拍摄角度、距离和光线一致。

可执行示例：封面格式：同一案例｜第X天回访。内容固定三问：和上次相比有什么变化？目前最在意什么？下一次需要观察什么？

为什么：统一时间和拍摄条件有助于比较，减少妆容、光线与角度变化造成的误读。

意义与复盘：让案例形成可追踪的过程，减少仅展示最好状态带来的信息空缺。用系列回访观看与问题变化评估价值。

01 / 四类主栏目

项目案例

讲清这一个案例为什么这样安排，以及后面如何观察。

  1. 01顾客诉求
  2. 02方案依据
  3. 03关键过程
  4. 04当次反馈
  5. 05后续观察
脚本容易卡在哪里

只有操作镜头和效果词，顾客诉求、方案依据与观察时点容易断开。

开头钩子
用一句真实诉求，让观众知道这条要看哪个问题。

核心看点
同一个诉求，为什么只保留这些判断和过程。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：让操作镜头对应一个明确的目标，反馈也能回到最初诉求。

意义：从“展示做了什么”变成一条可追踪的案例，便于制作后续回访。

开场句式示例：她这次最在意的是［真实诉求］。我们先确认［信息］，再决定本次重点。

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 顾客诉求顾客原话交代主要困扰与期待，一次只保留一个主诉。顾客一句原声＋对应部位的原始画面；不代写她的感受。先建立观看任务。
02 方案依据医生解释核实了哪些信息、本次目标和取舍；没有做的部分如有真实原因可交代。保留原声判断及对应示意；专业信息由医生填实。让后面的过程有依据。
03 关键过程挑两三个与本次目标有关的节点，说明为什么需要它。一段过程配一句原因；同类动作压缩，保留必要条件。每个镜头都推进同一条主线。
04 当次反馈区分顾客当下感受与医生观察，明确反馈发生的时间。反馈原声与时间标注对应；即时状态不写成长期结论。回答当次发生了什么。
05 后续观察交代尚不能判断的部分，以及实际安排的下一观察点。用原有医嘱／回访安排收束；没有后续素材就明确待观察。留出完整记录的后半段。

剪辑节奏：先把问题说清，再给依据；重复操作合并，判断条件和观察时点保留。候选 A 仍以 40–60 秒试剪，素材不足不硬凑。

02 / 四类主栏目

面诊案例

让观众看到医生如何把诉求变成有依据的共识。

  1. 01顾客诉求
  2. 02医生追问
  3. 03判断依据
  4. 04方案取舍
  5. 05双方确认
脚本容易卡在哪里

寒暄和完整顺剪拖慢进入主题；只留医生结论又会丢失追问与取舍。

开头钩子
先放顾客的真实诉求，或本次面诊最关键的一句追问。

核心看点
顾客原本想要什么，哪些信息让医生继续追问、调整目标。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：让每个追问承接上一句，方案由真实信息推导出来。

意义：具体呈现医生的思考方式，也让顾客是否理解方案可被看见。

开场句式示例：你说的［诉求原话］，具体是从什么时候、在什么情况下开始在意的？

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 顾客诉求保留顾客最想解决的问题、期待及最在意的部分。先顾客原声，再用关系镜头说明双方在交流。明确本次讨论对象。
02 医生追问保留确实影响判断的追问；背景信息按相关性取舍。问题与原回答成对保留；删寒暄，不拼出不存在的因果。补足作判断所需的信息。
03 判断依据医生解释观察到什么、还缺什么、哪些信息支持当前判断。原声解释对应指认或示意；图片只能说明已能看见的部分。让专业判断可理解。
04 方案取舍解释本例考虑了哪些方向、为什么选择或暂缓，以及限制。保留一个关键取舍与理由，不罗列全部项目。让选择有理由，避免直接跳到项目名。
05 双方确认确认顾客是否理解目标、限制和下一步；允许仍有疑问。保留顾客复述或真实追问、医生确认；不把沉默剪成同意。形成这次交流的真实结论。

剪辑节奏：压缩寒暄，保留改变判断的追问；在依据与取舍处留足时间，确认不能一带而过。

03 / 四类主栏目

科普

围绕一个现象，讲清一个为什么。

  1. 01常见疑问或误区
  2. 02核心结论
  3. 03原理解释
  4. 04适用边界
  5. 05判断要点
脚本容易卡在哪里

术语先行、多个知识点平铺，观众不知道哪个解释与自己有关。

开头钩子
抛出观众能识别的现象或误区，不制造容貌焦虑。

核心看点
从表面现象到原因之间，补上观众原本缺的一层解释。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：先回答观众的疑问，再解释原因与限制，降低理解门槛。

意义：形成能被复述和收藏的知识栏目；张路仍作为科目组织参考。

开场句式示例：为什么只看一张照片，还不能把一个人的情况说完整？

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 常见疑问或误区选一道日常疑问或明确误区，不把所有抗衰知识放进一条。首帧问题与医生第一句一致；示例明确标作示意。让观众知道这条解释什么。
02 核心结论先给一句可以理解的回答，别等到结尾才出现。医生直答，字幕突出核心意思，避免绝对化。尽早兑现开头。
03 原理解释用一个原因链或对照解释结论；事实与来源需能核查。原声配示意图或经核实资料；图只解释当前概念。让结论有依据。
04 适用边界说明什么条件下成立、哪些情况不能直接套用。条件紧贴相关结论；不能只放结尾小字。避免观众把一般解释当个人诊断。
05 判断要点用一句话复述观察或理解要点，回到开头问题。收束到一个记忆点，不追加多个新项目或话题。让观众带走可复述的答案。

剪辑节奏：结论前置，解释只留一条主线；术语出现时立即解释，适用条件紧随结论。

04 / 四类主栏目

Q&A

让一道真实问题得到完整、直接的回答。

  1. 01真实提问
  2. 02直接回答
  3. 03理由解释
  4. 04分情况补充
  5. 05一句总结
脚本容易卡在哪里

多问挤在一条里，封面没有主问题，答案需要观众自己寻找。

开头钩子
把一道完整问题放在封面、首帧和第一句。

核心看点
先满足“答案是什么”，再解释“为什么不能一概而论”。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：提问、答案和条件紧邻，观众不必跨多个问题找信息。

意义：方便检索、收藏与转发，也能从新问题继续排选题。

开场句式示例：观众问：面诊前可以准备哪些信息？医生先简答，再补充具体原因。

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 真实提问用真实评论、面诊常问或现有片段中的原问；只选一问。匿名问题卡或原声提问；没有真实评论截图就不伪造。明确内容入口。
02 直接回答先给简答；若不能统一回答，就直接说需要看哪些信息。提问后马上接回答，删除无信息的开场套话。迅速兑现标题。
03 理由解释解释这一答案背后的一个关键原因，必要时给一个例子。一个理由对应一段画面或示意，例子不冒充真实病例。让回答不止于结论。
04 分情况补充补充会改变回答的条件，不把同一答案套给所有人。字幕随原声标出条件；过长的分支另做一条。保留答案的准确范围。
05 一句总结用一句话收回原问题；未确定部分明确标出。结尾仍回答同一道题，不突然转为促销口播。形成可以单独使用的一条问答。

剪辑节奏：问完即答；理由最多抓一两个重点，分支很多时拆下一条，不重新堆成多问合集。

既往项目后困扰／修复主题

讲清期待落差，以及为什么要重新核实信息。

  1. 01原本期待
  2. 02当前困扰
  3. 03信息核实
  4. 04调整取舍
  5. 05后续观察
脚本容易卡在哪里

只用“做坏了”制造冲突，或直接推荐下一个项目，会跳过事实核实。

开头钩子
用真实的期待落差开题，不先替顾客或其他医生下结论。

核心看点
原期待与目前状态之间，哪些信息仍缺失、哪些影响下一步。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：把矛盾落在具体事实与信息缺口上，后续调整才有清楚依据。

意义：与首次项目案例区分，呈现谨慎评估与期待沟通。

开场句式示例：她原本想改善［诉求］，现在最在意的是［真实困扰］。下一步前，我们先核实这些信息。

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 原本期待说明之前希望得到什么，只保留与当前问题相关的信息。顾客回述原期待；没有旧素材就不做伪造的“此前画面”。建立原始目标。
02 当前困扰交代现在具体不满意什么、出现多久，区分感受与可观察事实。原声＋明确时点的当前画面；不用夸张特效制造问题。把落差说具体。
03 信息核实核实既往经历、资料和仍不确定的信息，暂不认定原因。医生追问与资料说明对应，遮去无关个人信息。先建立判断基础。
04 调整取舍解释为什么考虑调整、暂缓或继续观察，保留限制。一个关键取舍配一条真实依据，不剪成统一修复方案。让下一步有理由。
05 后续观察交代实际观察安排、仍需确认的事项及后续记录。已发生的回访才能作为后续；没有就留为待观察。不把本次处理写成完美结局。

剪辑节奏：期待与困扰快速成对交代，把篇幅留给核实和取舍；不为反转删除不确定性。

全流程记录

把每个流程节点变成一个能被理解的信息节点。

  2. 02准备说明
  3. 03关键步骤及原因
  4. 04过程中的确认

脚本容易卡在哪里

按时间堆操作或一味加速，观众看见动作，却不知道每步为何存在。

开头钩子
开头说明这次流程围绕哪个问题，而不只写“全流程”。

每一步为什么需要、这一阶段确认了什么、为什么进入下一步。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：把时间顺序与信息目的连接起来，长片也有清楚的观看路线。

意义：短版保留主要节点，长版补充细节，两版共用真实素材但任务明确。

开场句式示例：这次记录重点看［目标］。下面这几个节点，分别解决不同的问题。

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 本次目标说明本次记录的目标、范围与具体案例背景。目标字幕＋相关原声，封面范围与正文一致。让观众预先知道看什么。
02 准备说明交代准备阶段做什么以及为什么，只保留理解所需信息。原声解释配准备画面；无关等待压缩。让后续步骤有上下文。
03 关键步骤及原因每个关键节点同时交代做什么、为什么保留这一段。节点名＋必要现场画面；不提供可供自行操作的教程。避免只展示手上动作。
04 过程中的确认保留真实的沟通、反馈和确认，交代其对下一步的影响。确认发生在哪里，就接在哪里；不事后拼接虚假回应。让流程体现互动与判断。
05 结束交代交代本次完成范围、当前状态及实际后续安排。标明时间，不把流程结束当作效果已经确定。给整条记录一个完整收束。

剪辑节奏：按信息节点分章；每个关键步骤边展示边解释，确认穿插在对应节点，不统一堆在结尾。

项目体验

回答顾客在过程中实际经历了什么。

  1. 01做前顾虑
  2. 02实际经历
  3. 03当下感受
  4. 04医生回应
  5. 05后续记录
脚本容易卡在哪里

顾客只当背景人物，体验靠旁白代写，或把单人的感受包装成普遍保证。

开头钩子
从一个真实顾虑切入，给观众进入现场的理由。

核心看点
预期与实际体验有什么差异，医生如何回应具体感受。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：顾客讲个人经历，医生解释相关条件，两种声音各自负责事实。

意义：增加真实交流，帮助观众理解流程信息，不把感受当疗效证据。

开场句式示例：开始前，你最想先确认什么？／刚才这一阶段，你的实际感受是什么？

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 做前顾虑记录开始前最关心的一件事，保留真实措辞。顾客原声开场，不预先指定她应紧张或满意。建立体验视角。
02 实际经历展示与该顾虑有关的实际节点，说明正在经历什么。保留必要现场信息，避免大量无关操作画面。让感受有对应场景。
03 当下感受询问该节点的实际感受，具体到当时，不概括所有人。同步原声与画面；不把表情解读成未说过的感受。给出个人体验记录。
04 医生回应医生回应这条具体反馈，说明本例条件与仍需观察之处。顾客反馈后接医生真实回应，不补写医学原因。让体验与专业解释相连。
05 后续记录交代下一次记录节点；暂时没有后续就明确说明。时间标注配实际安排，不用一次感受代表长期状态。保留体验随时间变化的空间。

剪辑节奏：每个关键节点只保留有新信息的感受；实际经历、感受与医生回应相邻。

只给最好看的状态，缺少时点和可比条件，变化难以判断。

开头钩子
开头明确同一案例、距项目或上次回访多久。

核心看点
相同问题在不同时间点如何变化，哪些仍不能下结论。

怎么改 · 为什么 · 意义

怎么改：按上面五步选素材，把每一步要说的话和对应画面对齐。

为什么：时间和拍摄条件可核对，才有基础解释变化及不确定性。

意义：把单条案例延伸成连续记录，积累长期观察而非单次展示。

开场句式示例：同一案例，这次是实际记录的第［X］天。我们继续看上次关注的［问题］。

展开五步脚本：每步写什么、拍什么、为什么保留
步骤写什么／说什么拍什么／怎么剪这一步的作用
01 时间坐标写清日期、距项目或上次回访的间隔，不套统一恢复天数。第一屏时间卡，所有前后素材对应各自拍摄时间。定位本条在时间线中的位置。
02 当前状态记录顾客自述和当前能看到的状态，二者分别表达。保留当前原声与画面，不只挑最好看的片段。说明今天发生了什么。
03 与上次对照围绕同一问题与已有记录比较，说明拍摄条件是否可比。尽量同角度、光线和表情；条件不一致时标明局限，不用AI补造变化。给比较提供上下文。
04 医生解释医生解释目前可判断什么、尚不能判断什么。解释对应具体观察点，不由编辑代写恢复结论。区分观察与结论。
05 下一观察点交代实际后续观察或回访安排，回到原先关注的问题。结尾保留下一次要继续看的同一观察点。让系列有连续性。

剪辑节奏：时间坐标先交代，再围绕同一观察点比较；切换前后图时留出辨认时间，不用快闪代替解释。

一份素材，先选一个主任务。

面诊讲清判断与共识；项目讲清必要过程；回访讲清时间变化。素材完整且各自满足发布要求时再拆片。Q&A 从一个真实问题切入，科普围绕一条解释主线展开。

写稿顺序：选类型 → 填五步真实信息 → 标原素材位置 → 找缺口 → 决定删减或补拍。缺哪一环就标哪一环，不用旁白补造事实。
