01 · 刘岱良

项目面诊：把「过程」改成「判断过程」

原片依据与内容拆解

已核实：已看到顾客描述年龄与困扰、医生在面部标记解释。原片约2分10秒；页面约1.4万赞。尚未完整核对开头与结尾的镜头顺序。

钩子：标题把年龄与具体困扰放在一起，便于同类人群识别。实际首2秒是否兑现这一承诺，仍待逐秒核实。

看点：值得研究的是：顾客怎么说、医生看什么、为什么这样判断。面部标记使口头解释有可指认的位置。

珊珊对应问题 → 优化方案

对应问题：珊珊的项目作品，标题讲双眼变化、封面强调全流程，抽查开场字幕为「塑形中」。用户进入后需要重新判断这条到底解决什么问题。

怎么改：封面、首句和正文统一为一个诉求；先保留顾客的一句原话，再给医生对应部位的判断镜头。避免用泛泛的「全脸年轻化」包住所有变化。

可执行示例：封面示例：眼周显疲惫，面诊先看什么？开头示例：她最在意的是眼周看起来疲惫，面诊时我先确认这两个信息。具体信息由医生按真实病例填写。

为什么：先让观众知道自己在看什么，再用可见证据解释方案；能减少内容范围不明带来的理解成本。

意义与复盘：从展示做了什么，转向展示医生如何思考。复盘前5秒留存及评论里是否出现与该诉求相关的具体提问，不能仅看总赞。

建议剪辑节奏 · 非原片时间轴

建议剪辑版45–60秒：0–3秒具体诉求；3–10秒顾客背景；10–28秒判断依据；28–45秒与判断相关的过程；45–60秒个案反馈与观察时间。

02 · 勾涛

修复主题：一个矛盾，撑起一条视频

原片依据与内容拆解

已核实：已核对标题「菱形脸填完脸更大了？」、原封面及互动；约1分钟，约1万赞、7676收藏。尚未逐镜核实三步的内容。

钩子：标题存在明确的期待落差：原本希望改善，为什么反而更不满意？这是标题层面的疑问，不等于已经验证了原片开头。

看点：观众需要一个解释这次不满意的判断过程，而不仅是另一个项目名称。原封面的醒目文字也在强调同一个疑问。

珊珊对应问题 → 优化方案

对应问题：当项目内容同时讲多个部位、多个项目和整个流程，主问题容易被信息量淹没。对珊珊新案例应先确定一条片只回答什么。

怎么改：单列「已有项目后仍有困扰」主题。交代顾客期待、目前观察、需核实的信息，再讲医生如何决定下一步，不先给所有同类脸套统一方案。

可执行示例：封面示例：做完后仍不满意，面诊先核对什么？开头用真实顾客的一句疑问，医生随后解释这一例还缺哪些判断信息。

为什么：具体矛盾能限定选题范围，后面的每个镜头都有对应任务；更容易避免大量知识点平铺。

意义与复盘：让修复案例与初次项目案例形成不同栏目。检验评论是否围绕同一个问题，以及观众是否理解判断条件。

建议剪辑节奏 · 非原片时间轴

建议剪辑版45–60秒：0–4秒原期待与现困扰；4–15秒补背景；15–35秒解释关键判断；35–50秒方案选择依据；最后交代仍需观察的部分。

03 · 梁奕敏

全流程：每个步骤都要有观看理由

原片依据与内容拆解

已核实：原片约6分13秒。抽查开头讨论案例P图质疑；约2分07秒画面出现面部标记、镜前交流与消毒。仅确认这些观察点，不声称整条一镜到底或无处理。

钩子：开头处理的是「这是真的吗」这一信任问题。流程因此承担提供证据的任务，而不只是展示忙碌过程。

看点：标记位置、沟通动作、过程节点能帮助观众理解。长视频是否有冗余、各段是否持续提供新信息，尚需完整观看。

珊珊对应问题 → 优化方案

对应问题：珊珊封面用「全流程」作承诺，但标题更突出眼周变化。流程与观看目标需要明确连接。

怎么改：同一案例做两个版本：45–75秒讲清关键判断；3–6分钟记录详细流程。短版每一步配一句「为什么保留这一步」，长版加清晰章节；不要靠加速堆满所有素材。

可执行示例：建议章节：顾客诉求 → 判断依据 → 准备说明 → 关键过程 → 当次反馈。结果画面注明拍摄时间，不把即时状态说成长期结果。

为什么：不同观看深度需要不同的信息量。短版让人迅速理解，长版让有具体疑问的人继续查阅。

意义与复盘：建立可核查的案例记录。分别看短版前段留存、长版各章节流失与具体问题评论；不能将长版播放少直接判为无价值。

建议剪辑节奏 · 非原片时间轴

建议短版：0–5秒这次解决什么；5–20秒判断；20–45秒两三个必要过程；45–75秒反馈与边界。长版按信息节点切章节，不机械按秒切镜。

04 · 王恒

面诊Q&A：让问题推动回答

原片依据与内容拆解

已核实：约55秒；抽查开头可见就诊者在诊室提出注射相关诉求。页面约3万赞、3.9万收藏、1.6万分享。未验证对话是否自然发生、是否经过编排。

钩子：「内行人」是身份标签，能制造对话期待；真正可以迁移的是一个具体问题，而不是照抄身份设定。

看点：问答双方、诊室场景和即时表达使内容有交流感。收藏和分享较高是公开互动信号，不能推断转化原因。

珊珊对应问题 → 优化方案

对应问题：珊珊的快问快答封面同时列多道问题，点击前不容易确认最主要的观看收益。

怎么改：从现有素材里按问题拆片。封面只写一道完整问题，开头保留提问，医生先简答，再说明适用条件。扩展问题做下一条，并归入同一合集。

可执行示例：封面示例：面诊时，为什么要问以前做过什么？首句直接重复真实问题；随后给简答与这次病例相关的解释。

为什么：一问一答降低信息筛选负担，也让封面、首帧与正文更容易一致。

意义与复盘：方便观众查找与收藏，同时积累下一批真实问题。复盘有效提问数量、收藏率和该片完播，后台可得时再比较。

建议剪辑节奏 · 非原片时间轴

建议20–40秒：0–3秒提问；3–8秒直接简答；8–25秒理由或条件；25–40秒说明哪些信息仍需面诊核实。

05 · 宋一妍

项目体验：加入顾客正在经历什么

原片依据与内容拆解

已核实：约77秒，7548赞。已在约30秒核对光电操作实拍；页面有操作前、过程、操作后章节，但平台AI章节摘要不能替代原片事实核对。

钩子：标题「带你云体验」给出参与感，承诺的是体验过程。不能用这类体验作品证明医生的专业判断或项目效果。

看点：操作现场提供进入场景的入口。下一步应逐句核实顾客感受是否具体、是否交代时间，不能根据画面代写她的感受。

珊珊对应问题 → 优化方案

对应问题：珊珊项目案例如果连续保留相似操作镜头，用户可能看到动作变化，却不知道顾客为什么在意、正在经历什么。

怎么改：在取得授权的真实素材中，补三处顾客声音：做前最关心什么、过程中实际感受、做后当下反馈。医生负责判断与条件说明，顾客负责个人体验。

可执行示例：拍摄提问示例：开始前你最想确认什么？现在实际感受和想象有什么不同？今天结束后，还有什么问题想问？保留真实回答。

为什么：体验与专业解释承担不同的信息任务。补上顾客声音，可让操作镜头与真实疑问产生联系。

意义与复盘：让项目内容更贴近观看者的信息需求。评价评论里对流程、恢复和注意事项的提问，而非把情绪热度等同于意向。

建议剪辑节奏 · 非原片时间轴

建议60–90秒：前5秒交代诉求；5–20秒准备与疑问；20–55秒挑选有新信息的过程；55秒后当次感受与后续观察安排。

06 · 陈陈

恢复回访：时间本身就是栏目线索

原片依据与内容拆解

已核实：约54秒，2401赞、1086评论。开头画面与字幕明确「眼周提升第五天」，可见恢复状态。未核实后续恢复结局。

钩子：第5天是明确的时间坐标，让正在关注恢复过程的人迅速知道这一条的价值。

看点：真实状态比笼统的「恢复得很好」更具体。不能根据这一个人的画面，推导其他人的恢复时长。

珊珊对应问题 → 优化方案

对应问题：项目案例如果只拍当天前后，难以回答观众对后续变化的疑问。这是珊珊可补充的栏目机会，不是声称已审完全部作品后的缺失结论。

怎么改：为同一案例建立按实际复诊安排更新的回访系列。每条固定写清距项目多久、顾客自述、可见状态与医生解释；尽量保持拍摄角度、距离和光线一致。

可执行示例：封面格式：同一案例｜第X天回访。内容固定三问：和上次相比有什么变化？目前最在意什么？下一次需要观察什么？

为什么：统一时间和拍摄条件有助于比较，减少妆容、光线与角度变化造成的误读。

意义与复盘：让案例形成可追踪的过程，减少仅展示最好状态带来的信息空缺。用系列回访观看与问题变化评估价值。

建议剪辑节奏 · 非原片时间轴

建议30–60秒：0–3秒时间坐标；3–15秒当前状态；15–35秒顾客反馈；35–60秒医生解释与下一观察节点。

三类栏目，各自承担不同任务

项目：具体诉求 → 判断依据 → 必要过程 → 按时间交代个案反馈。
科普：一道明确问题 → 第一层解释 → 条件与例外 → 相关问题索引；张路作为科目组织参考。
Q&A：原问 → 简答 → 原因或条件 → 仍需核实的信息；丹丹作为同赛道问题型封面参考。

节奏先看信息是否推进：连续镜头表达同一件事时压缩；解释关键判断时留足时间。切镜数量、时长短或背景音乐快，都不能单独说明节奏好。
